# 0005. 推移グラフは matplotlib の PNG をメールに埋め込む

- ステータス: Accepted
- 日付: 2026-10-04

## 背景

数値だけでなく推移も一目で見たい。API の `fear_and_greed_historical` に約 1 年分の日次スコアが含まれているので、追加の取得なしで描ける。

## 決定

matplotlib で過去 6 ヶ月の推移を PNG に描き、HTML メールに Content-ID（`cid:chart`）で埋め込む。背景に 5 区分の帯（悲観 = 赤、中立 = グレー、楽観 = 青）を敷く。テキスト版も同じ本文で残す（multipart/alternative）。描画に失敗してもグラフなしで数値のメールは送る。

## 選ばなかった選択肢

- **QuickChart などの外部画像 URL を `<img src>` に入れる**: 依存は増えないが、データを第三者に渡すことになり、メールを開くたびに外部サービスが生きている必要がある
- **SVG を埋め込む**: Gmail が SVG を表示しない
- **PNG を添付ファイルにする**: 開く手間が増える。本文で見えるのが目的
- **自前で PNG を描く（標準ライブラリのみ）**: 軸・帯・ラベルを手で描くことになり、保守に見合わない

## 影響

- 依存に matplotlib が加わり、標準ライブラリだけでは動かなくなった。Actions では pip キャッシュを使う
- 区分ラベルは英語にした。Actions のランナーに日本語フォントがなく、日本語だと文字化けするため
