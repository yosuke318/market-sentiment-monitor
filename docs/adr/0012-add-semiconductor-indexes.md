# 0012. 米国の SOX 指数と日本の半導体株（ETF 200A で代用）を本文に足す

- ステータス: Accepted
- 日付: 2026-10-10

## 背景

半導体株は景気やハイテク株の先行指標として見られ、日経平均の値がさ株（東京エレクトロン・アドバンテストなど）とも連動しやすい。0011 の NT 倍率とあわせて読めるよう、米国と日本の半導体株の動きもメールで見たい。

## 決定

- **米国**: フィラデルフィア半導体株指数（`^SOX`）を、Fear & Greed のセクションに日経平均株価と同じ形（終値と騰落率の比較）で出す
- **日本**: 日経半導体株指数は Yahoo Finance に無いので、連動する ETF「NEXT FUNDS 日経半導体株指数連動型 ETF」（`200A.T`）の価格で代用する。本文に代用であることを書く
- 取得はどちらも TOPIX と同じ Yahoo の chart API。`topix.py` を銘柄共通の `yahoo.py` にした
- 日本の ETF は実行時刻（09:30 JST）が取引時間中なので、日経平均の最終日以前に切る。日経平均が取れない日は前日以前に切る
- グラフには足さない（日経平均のグラフは線が 3 本あり、これ以上は読みにくい）

## 選ばなかった選択肢

- **日経公式サイトの日経半導体株指数の CSV**: 日経平均・VI と同じ取得元にできれば ETF より正確だが、配布されている CSV のファイル名を確認できなかった。確認できたら差し替える
- **SOX に連動する日本の ETF・投信**: 為替が混ざり、米国の半導体株そのものの動きが読めない

## 影響

- ETF の価格は指数そのものではない。騰落率はほぼ同じだが、信託報酬や分配金の分だけずれる。ETF は 2024 年 7 月上場なので、それより前とは比べられない
- いずれも非公式 API で、取得に失敗した日は本文に失敗と書き、残りは今まで通り送る
