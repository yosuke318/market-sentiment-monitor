# 0010. TOPIX を日経平均のグラフに緑の 3 本目の軸で足す

- ステータス: Accepted
- 日付: 2026-10-09

## 背景

日経平均株価と日経平均VIのグラフ（0008）に、TOPIX も同じ枠で重ねて見たい。TOPIX は日経の CSV に含まれない。また日経平均（6 万円台）と TOPIX（3 千台）は桁が違うので、同じ軸には載らない。

## 決定

- 取得元は Yahoo Finance の chart API（`^TOPX`、日次、直近 3 年）。API キーは不要で、追加の依存パッケージもいらない（`topix.py`）
- 左軸の外側に独立した 3 本目の軸を張り出し、緑（`#1f9d62`）で描く。軸の範囲は他の軸と同じく最小〜最大から自動で取る。軸名は `TOPIX (left, outer)`
- 緑は日経平均（オレンジ）・VI（青）と見分けがつき、Fear & Greed の帯（赤・青）とも混ざらない
- TOPIX の最終日は日経平均の最終日以前に切る。実行時刻（09:30 JST）は東証の取引時間中で、Yahoo は当日の取引中の値を最終行に含めるため
- 右端の値ラベルは、日経平均と TOPIX が連動して重なりやすいので上下にずらす
- グラフに足すだけで、本文の数値（前日比など）は付けない

## 選ばなかった選択肢

- **日経平均と同じ左軸に載せる**: 桁が違い、TOPIX が下に張り付いて動きが読めない
- **2 本とも指数化（開始日 = 100）**: 日経平均の円での水準が読めなくなる（0007 の VI と同じ理由）
- **yfinance パッケージ**: chart API を 1 回呼ぶだけなので、依存を増やすほどではない
- **JPX / stooq の CSV**: JPX は TOPIX の日次終値を配布しているが公式ページの形式が頻繁に変わる。stooq はブラウザ検証があり不安定（0006）

## 影響

- Yahoo の chart API は非公式で、仕様変更や取得拒否がありうる。取得に失敗した日は TOPIX だけ省き、日経平均と VI のグラフと数値は今まで通り送る
- 左軸が 2 本あるので、どちらの軸の線か色と軸名で読む。線同士の交差に意味がないのは 0008 と同じ
- TOPIX の取得元は Yahoo の利用規約の範囲（個人の自分宛て通知）に留める。データはリポジトリに保存しない
