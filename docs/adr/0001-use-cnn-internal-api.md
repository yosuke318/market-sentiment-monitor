# 0001. データ取得に CNN の内部 API を使う

- ステータス: Accepted
- 日付: 2026-10-04

## 背景

Fear & Greed Index の公式な公開 API はない。CNN のページは `https://production.dataviz.cnn.io/index/fearandgreed/graphdata` から JSON を取得して描画している。

## 決定

この内部 API を直接叩く。User-Agent などブラウザ相当のヘッダーを付ける（付けないと 418 が返る）。区分は API が返す `rating` をそのまま使う。

## 選ばなかった選択肢

- **ページの HTML をスクレイピング**: 値は JS で描画されるため HTML に含まれず、ヘッドレスブラウザが必要になる。重く、壊れやすさは内部 API と変わらない
- **サードパーティのラッパー（PyPI の fear-and-greed 等）**: 中身は同じ内部 API を叩いているだけで、依存が増える分だけ損
- **スコアから区分を自前で計算**: 境界値（25, 45, 55, 75）の含み方が CNN の表示とずれる恐れがある。`rating` を使えば CNN の表示と必ず一致する

## 影響

非公式 API なので予告なく仕様変更・ブロックされうる。取得に失敗するとジョブが失敗し、GitHub から失敗メールが届くのでそれで気づける。
