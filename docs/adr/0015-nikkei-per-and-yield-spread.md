# 0015. 日経平均の PER と 10 年債利回りからイールドスプレッドを出す

- ステータス: Accepted
- 日付: 2026-10-28

## 背景

VI や Fear & Greed は「不安の強さ」は示すが、「株価が下がって割安になったのか」は示さない。株価の水準を利益と金利に照らして見る指標がほしい。

## 決定

- **日経平均の PER**: 日経の指数公式サイトのヒストリカルデータ（日次投資指標、`nkave/archives/data?list=per`）の表を HTML から読む。CSV は配布されていない（候補の URL は 403）。過去の月は `nkave/statistics/dataload?list=per&year=…&month=…` で取る。比較（前日比〜1年前比）に要る 4 か月分（前月・前々月・1年前の月とその前月）だけ取り、過去の月は取れた分だけ使う
- **10 年債利回り**: 財務省の国債金利情報 CSV。全期間（`data/jgbcm_all.csv`、前月末まで）と当月分（`jgbcm.csv`）を合わせる。当月分は月初に空になりうるので、全期間で補う。日付は和暦（`R8.10.27`）を西暦に直す
- **イールドスプレッド**: 株式益回り（100 ÷ PER）− 10 年債利回り。利回りは PER と同じ日がなければ、その日以前で最も近い日を使い、本文に両方の日付を書く（財務省の公表は翌営業日の昼ごろで、毎朝 9:30 の実行では 1 日古いことが多い）
- PER は加重平均（新聞に載る値）を主にし、指数ベースは参考で並べる。スプレッドも加重平均 PER から出し、指数ベースの値を 1 行添える
- 2026-10-28 に GitHub Actions から、PER のページ（当月・過去の月）と財務省の CSV 2 本がいずれも取れることを確かめた（ブラウザ検証なし）

## 選ばなかった選択肢

- **第三者のサイトの PER（stock-marketdata.com など）**: 規約と安定性の面で避ける
- **指数ベース PER を主にする**: 新聞・証券会社の解説の多くは加重平均で、読み比べにくい

## 影響

- 表は HTML なので、日経のページの作りが変わると読めなくなる。その場合は本文に取得失敗と書き、残りは送る（0006 と同じ）
- PER が予想か前期実績かは、ページに書かれていない（計算式はユーザーズ・ガイドを参照、とだけある）。本文では種類を書かず「加重平均」「指数ベース」とだけ書く
- 日経の著作物なので、0006 と同じく自分宛ての通知で見る用途に留め、データはリポジトリに保存しない
