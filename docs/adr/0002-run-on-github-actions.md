# 0002. GitHub Actions の schedule で実行する

- ステータス: Accepted
- 日付: 2026-10-04

## 背景

1日1回、数秒で終わる処理を定期実行したい。サーバーの常時稼働は不要。

## 決定

GitHub Actions の `schedule`（毎日 00:30 UTC = 09:30 JST）で実行する。米国市場の終値確定（CNN のデータ時刻は 23:59:58 UTC）後のタイミング。

## 選ばなかった選択肢

- **ローカルの cron / launchd**: Mac がスリープ・電源オフだと実行されない
- **Vercel Cron / Cloud Functions など**: 動くが、前回状態を持つためにストレージを別途用意する必要がある（0003 参照）。GitHub Actions ならリポジトリ自体を保存先にできる
- **Claude Code のスケジュール実行**: 決まった処理を毎日回すだけなので LLM を挟む必要がない

## 影響

- schedule は混雑時に数十分遅れることがある。日次通知なので許容する
- リポジトリに 60 日間アクティビティがないと schedule は無効化されるが、0003 で状態を毎営業日コミットするため実質発生しない
