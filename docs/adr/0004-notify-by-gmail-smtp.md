# 0004. 通知は Gmail の SMTP でメール送信する

- ステータス: Accepted
- 日付: 2026-10-04

## 背景

当初は Slack / Discord の Incoming Webhook に送っていたが、普段使っているのはメールなので、通知はメールだけにする。1日1通、自分宛て。

## 決定

Gmail の SMTP（`smtp.gmail.com:465`、SSL）からアプリ パスワードで認証して送る。Python 標準の `smtplib` を使い、依存は増やさない。Slack / Discord への送信は削除する。

件名に区分とスコアを入れ、区分が変わった日は先頭に【区分変化】を付ける。メール一覧の件名だけで変化に気づけるようにするため。

## 選ばなかった選択肢

- **Slack / Discord の Webhook と併用**: 使わない通知先のコードとシークレットを残す理由がない
- **メール配信サービス（Resend / SendGrid 等）**: アカウント登録と API キー管理が増える。独自ドメインからの大量配信向けで、自分宛て 1 日 1 通には過剰
- **GitHub Actions の失敗通知メールを流用**: 失敗時にしか届かず、本文も指定できない

## 影響

- 送信元 Google アカウントの 2 段階認証とアプリ パスワードが必要。パスワードを変えるとアプリ パスワードが無効になることがあり、その場合はジョブが認証エラーで失敗する
- 自分宛てに送る場合、Gmail では受信トレイではなく「送信済み」と同じスレッドに入ることがある
