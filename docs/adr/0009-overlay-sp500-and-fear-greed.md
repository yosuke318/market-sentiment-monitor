# 0009. S&P500 と Fear & Greed も左右 2 軸で重ねる

- ステータス: Accepted
- 日付: 2026-10-04

## 背景

日本側（0008）と同じく、米国側でも心理指標と株価の重なりを見たい。

## 決定

Fear & Greed の単独グラフ（0005）を、左軸 S&P500（オレンジ）・右軸 Fear & Greed（黒）を重ねた図に置き換える。期間は過去 1 年。

- S&P500 は CNN の API が Fear & Greed と一緒に返す `market_momentum_sp500.data`（日次終値、約 1 年分）を使う。取得先は増やさない
- 右軸は 0〜100 に固定し、背景に Fear & Greed の 5 区分の帯を敷く。帯と同系色にならないよう Fear & Greed の線は黒にする
- 帯は S&P500 の線の背景にもなり「S&P500 が Extreme Greed にある」と誤読されうるので、単独グラフの半分の濃さにし、左軸の横グリッドは消して横方向の基準を帯（右軸）だけにする
- S&P500 のデータが API から消えた場合は、従来の Fear & Greed 単独グラフ（6 ヶ月）に戻す

## 選ばなかった選択肢

- **Yahoo Finance など別の取得先から S&P500 を取る**: CNN の API に同じ期間の終値があり、依存も失敗点も増やす理由がない
- **区分の帯をやめる**: 区分の変化を通知している以上、今どの区分にいるかは図でも見えるべき
- **期間を日経と揃えて 2 年半にする**: CNN の API が約 1 年分しか返さない

## 影響

- 左右 2 軸の注意点（線の交差に意味はない、重なりは因果を示さない）は 0008 と同じ
- `market_momentum_sp500` も非公式 API の一部なので、予告なく形が変わりうる
