# 0011. NT 倍率・VI の過去水準・Fear & Greed の内訳を本文に足す

- ステータス: Accepted
- 日付: 2026-10-09

## 背景

指標の数値だけでは「それが高いのか低いのか」「なぜそうなったのか」が分からない。新しい取得元を増やさず、すでに手元にあるデータで読み取りやすくしたい。

## 決定

- **NT 倍率（日経平均 ÷ TOPIX）**: 両方に終値がある日だけで計算し、他の指標と同じく前日・1週間前・1ヶ月前・1年前と比べる。TOPIX は 0010 で足した取得元をそのまま使う
- **VI の過去水準**: 日経の CSV 全体（直近 3 年ほど）の中で「上位何 %」か、中央値・最高・最低とあわせて 1 行で出す。自分自身を含めて数え、切り上げるので最高値でも 0% にはならない
- **Fear & Greed の内訳**: CNN の API が一緒に返す 7 つの構成要素（`market_momentum_sp500` ほか）それぞれの `rating` を、全体と同じ区分名と絵文字で並べる。生の値（S&P500 の水準など）は単位がばらばらなので出さない
- いずれも本文だけに足し、新着判定や件名は変えない

## 選ばなかった選択肢

- **NT 倍率のグラフ**: 日経平均・TOPIX・VI で 3 本の線がすでにあり、これ以上は読みにくくなる。必要になったら別の判断にする
- **構成要素ごとの 0〜100 のスコア**: API は構成要素の生の値と区分しか返さない。自前でスコアに直すと CNN の表示とずれる（0001 と同じ理由）
- **VI の期間を 1 年・5 年に固定**: CSV は 3 年分しかなく、他の期間を使うには別の取得元が要る

## 影響

- 構成要素の `rating` は非公式 API の一部で、形が変わりうる。読めない構成要素は省き、どれも読めなければ内訳ごと省く
- TOPIX が取れない日は NT 倍率を出さず、本文に取得失敗を書く（グラフからも TOPIX は省かれる）
- 「上位 %」は直近 3 年だけの相対位置で、長期の水準を表さない
