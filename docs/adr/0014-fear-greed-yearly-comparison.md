# 0014. Fear & Greed を過去 5 年で年ごとに重ねて比べる

- ステータス: Accepted
- 日付: 2026-10-27

## 背景

S&P500 と重ねたグラフ（0009）は直近 1 年の流れを見るもので、「今年の水準は例年と比べてどうか」は読めない。過去数年と同じ時期を並べて比べたい。

## 決定

- 年ごとに 1 本の線にし、横軸を 1〜12 月にそろえて重ねる。今年（YTD）を含む 5 年分
- 色は「何年前か」で固定する（今年＝青の太線、1 年前＝オレンジ、2 年前＝アクア、3 年前＝黄、4 年前＝マゼンタ）。どの年に見ても今年は青になる。基本パレットの順で、色覚の検証スクリプトを通した
- 区分（Extreme Fear〜Extreme Greed）は帯で塗らず、境目の薄い線と区分名で示す。帯の青・赤と年の線の色が混ざって読みにくくなるため
- グラフ内の文字は英語にする（Actions の Ubuntu に日本語フォントがないため。他のグラフと同じ）
- 本文には、グラフの見出しと「各年の同じ日付（なければその前で最も近い日）の値」を 1 行で添える
- 履歴は CNN の API に開始日を付けた `graphdata/<YYYY-MM-DD>` で取る。今の値の取得とは別に呼び、失敗してもこのグラフと見出しだけ省く

## 選ばなかった選択肢

- **5 年分を 1 本の時系列で描く**: 流れは追えるが、同じ時期どうしを比べにくい
- **年ごとの平均や分布（箱ひげ）**: 季節ごとの動きが消える

## 影響

- CNN の API が開始日の指定に対応しているか、どこまで遡れるかは開発環境から確認できていない。返ってきた範囲の年だけを描き、見出しの年の範囲もデータに合わせる
- 日次の値を 5 本重ねるので線は込み入る。過去の年は細く薄くして、今年を読みやすくしている
